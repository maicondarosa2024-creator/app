# 🛒 ML Agentes — instalação fácil

## Opção A: no seu computador (3 comandos)
```
npm install
npm run setup     # assistente: pergunta as chaves e cria o .env
npm start         # abre em http://localhost:3000
```
Requer Node 20+.

## Opção B: na nuvem (acessível no celular)
1. Suba esta pasta para um repositório no GitHub.
2. No Render (render.com): **New → Blueprint** e escolha o repositório.
3. Preencha as 4 variáveis pedidas. Em `ML_REDIRECT` use `https://SEU-APP.onrender.com/auth/callback`.
4. No Mercado Livre Developers, cadastre essa mesma URL como "URL de redirecionamento".

## Instalar no celular
Abra o endereço do app no navegador:
- **Android (Chrome):** menu ⋮ → *Instalar app*
- **iPhone (Safari):** Compartilhar → *Adicionar à Tela de Início*

Na primeira mensagem o app leva você ao login do Mercado Livre.
